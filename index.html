Инструкция

Что делает этот редактор
Он позволяет собрать форму, настроить поля и отправку в Discord. Ниже — краткая инструкция и практичные примеры.

Быстрый старт:

Вставьте ваш хук в поле Discord Webhook URL. Это адрес вида https://discord.com/api/webhooks/ID/TOKEN.

Заполните поля - интуитивно понятно.

Имя автора в Discord - это некая подпись которая находится внизу сообщения.

В поле Кастомное сообщение введите, если нужно, тег <@123456789012345678>, который необходимо упомянуть.

Добавьте нужные поля: Добавить поле → выбрать тип → дать имя. Сохранение происходит автоматически. Скопировать ссылку на форму — и используйте. Для коротких ссылок можно воспользоваться сервисом, например tinyurl.com.

Если сообщения не приходят — проверьте корректность адреса и права канала.

Типы полей

text / email / textarea — обычный ввод.

select / radio — списки, варианты вводятся через запятую.

mention — ожидает Discord ID пользователя (см. инструкцию), пример: 123456789012345678. Используйте, если хотите напрямую упомянуть пользователя.

При включении расширенные настройки, у полей типа mention появляется кнопка Не включать в embed при активации которой сообщение с этого поля не будет отображаться в embed и соответственно не попадет в Discord, но упоминание все равно придет.

computed — вычисляемое поле (см. ниже примеры).

Примеры вычисляемых полей

Используйте id поля (внутренний идентификатор) в фигурных скобках:

    {sum,fieldA,fieldB,...} — суммирует все числа, найденные в значениях указанных полей или поля (например, если в одной строке указано несколько чисел, они суммируются).
